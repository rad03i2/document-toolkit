# Contributing / المساهمة

Thank you for improving Document Toolkit. Keep pull requests focused and preserve the local-first, dependency-light design.

1. Fork or branch from `main`.
2. Use Node.js 20+.
3. Run `npm run check` and `npm test` before submitting.
4. Add tests for behavior changes and update both EN/AR README sections when user-facing behavior changes.
5. Do not commit secrets, generated output, personal documents, or large fixtures.
6. Prefer Node standard-library solutions unless a dependency has a clear maintenance and security benefit.

## Arabic / العربية
نرحب بالمساهمات. اجعل التغيير محددًا، وشغّل فحص الصياغة والاختبارات، وأضف اختبارًا لأي سلوك جديد. عند تغيير سلوك يراه المستخدم حدّث قسمي README الإنجليزي والعربي. لا ترفع أسرارًا أو مستندات شخصية أو ملفات مولدة، ويفضل الاعتماد على مكتبة Node القياسية ما لم توجد حاجة واضحة لاعتماد خارجي.
